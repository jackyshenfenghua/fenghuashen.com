# 运营管理智能自动化个人网站

静态个人主页，面向企业老板、高管、潜在客户和合作伙伴，展示业务理解、工程管理、运营管理和 AI 落地实践。

## 本地查看

直接打开 `index.html`，或运行：

```bash
npm run serve
```

然后访问 `http://localhost:4173`。

## 验证

```bash
npm test
```
